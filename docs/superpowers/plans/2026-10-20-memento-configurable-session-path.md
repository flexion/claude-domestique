# Memento Configurable Session Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Progress is recorded in the branch session file and at jay's review gates, not in this document; the filename template and migrating this repo's sessions are recorded as out of scope in the Design section only, with no backlog items.

**Goal:** Move memento's session and branch-metadata files out of `.claude/` to a default `.memento/` directory, let a repository override both directories in `.claude/config.json`, and keep sessions that already live under `.claude/sessions/` working.

**Architecture:** A new hand-written module `memento/lib/paths.js` is the single resolver for the sessions directory, branch-metadata directory, and per-branch session path (including the legacy fallback). Both hooks call it instead of building paths themselves. Skills, rules, and context docs stop naming a literal path and defer to the `📂 Session:` / `🗂️ Branch metadata:` lines the SessionStart hook injects, with a written fallback rule for when nothing was injected.

**Tech Stack:** Node.js 24, CommonJS, Jest 30 (`npm run test:memento`), Claude/Codex plugin manifests.

**Spec:** No separate spec file — this is a bounded change and the design was approved in chat. It is reproduced verbatim in [Design](#design-approved-in-chat) below; that section is the spec.

## Design (approved in chat)

**Config surface.** `.claude/config.json`, `memento` section, both keys optional and git-root-relative:

```json
{ "memento": { "sessionsDir": "work/sessions", "branchesDir": "work/sessions/.branches" } }
```

- Defaults: `sessionsDir` = `.memento/sessions`, `branchesDir` = `.memento/branches`.
- A key falls back to its default, and the hook injects a one-line `⚠️ memento:` warning, when its value is: not a string, empty/whitespace, contains a NUL character, absolute, resolves to the git root itself, or resolves outside the git root. A malformed `config.json` makes both keys fall back with one warning. A missing `config.json` or missing `memento` section is silent.
- Containment is checked lexically (`path.resolve` + `path.relative`); symlinks are not followed.

**Legacy fallback.** For branch `b` with sanitized name `s` (`/` → `-`):

1. `<sessionsDir>/s.md` exists → use it.
2. Else `<git-root>/.claude/sessions/s.md` exists → use it, flag `legacy: true`, inject a note offering `mkdir -p -- '<abs configured dir>' && git -C '<git-root>' mv -- '<legacy rel>' '<configured rel>'` (anchored to the git root so it works from any cwd), every argument POSIX single-quoted (embedded `'` written as `'\''`) so `$`, backticks, spaces, and quotes in a configured path are inert. Nothing is moved automatically. SessionStart does **not** create a new file.
3. Else → SessionStart creates `<sessionsDir>/s.md`.

If `sessionsDir` is configured to `.claude/sessions` itself, there is no legacy path (step 2 never fires).

**What each hook event injects.** SessionStart and a branch switch inject `📂 Session: <path>`, `🗂️ Branch metadata: <path>`, the legacy note (if legacy), and every config warning. A same-branch UserPromptSubmit injects `📂 Session: <path>` and every config warning (so a bad config is not forgotten after the first prompt), but not the metadata line or legacy note.

Branch-switch detection (`findPossibleSessions`, `detectMismatch`) searches both the configured sessions directory and `.claude/sessions/`, deduplicated.

**Out of scope:** the per-user HOME state file (`~/.claude/memento-state.json`); a filename template; moving this repository's own `.claude/sessions/*.md` files.

```js
/**
 * memento: session path resolution
 *
 * Single source of truth for where memento keeps session and branch-metadata
 * files. A repository can override both directories in .claude/config.json:
 *
 *   { "memento": { "sessionsDir": "work/sessions", "branchesDir": "work/.branches" } }
 *
 * Values are relative to the git root. Anything that is not a non-empty string,
 * is absolute, or resolves to the root itself or outside it falls back to the
 * default with a warning the hook injects into context.
 */

const fs = require('fs');
const path = require('path');

const DEFAULT_SESSIONS_DIR = path.join('.memento', 'sessions');
const DEFAULT_BRANCHES_DIR = path.join('.memento', 'branches');
const LEGACY_SESSIONS_DIR = path.join('.claude', 'sessions');
const CONFIG_FILE = path.join('.claude', 'config.json');

function sanitizeBranch(branch) {
  return branch.replace(/\//g, '-');
}

function readMementoConfig(gitRoot, warnings) {
  const file = path.join(gitRoot, CONFIG_FILE);
  if (!fs.existsSync(file)) return {};
  let parsed;
  try {
    parsed = JSON.parse(fs.readFileSync(file, 'utf8'));
  } catch {
    warnings.push('could not parse .claude/config.json; using default memento paths');
    return {};
  }
  const section = parsed?.memento;
  if (section === undefined) return {};
  if (!section || typeof section !== 'object' || Array.isArray(section)) {
    warnings.push('memento in .claude/config.json must be an object; using default memento paths');
    return {};
  }
  return section;
}

function resolveDir(gitRoot, key, value, fallback, warnings) {
  const defaultDir = path.join(gitRoot, fallback);
  if (value === undefined) return defaultDir;

  const reject = reason => {
    warnings.push(`memento.${key} ${reason}; using ${fallback}`);
    return defaultDir;
  };

  if (typeof value !== 'string' || value.trim() === '') return reject('must be a non-empty string');
  if (value.includes('\0')) return reject('must not contain a NUL character');
  if (path.isAbsolute(value)) return reject('must be relative to the git root');

  const resolved = path.resolve(gitRoot, value);
  const rel = path.relative(gitRoot, resolved);
  if (rel === '') return reject('must not be the git root itself');
  if (rel === '..' || rel.startsWith(`..${path.sep}`) || path.isAbsolute(rel)) {
    return reject('must stay inside the repository');
  }
  return resolved;
}

function resolveDirs(gitRoot) {
  const warnings = [];
  const config = readMementoConfig(gitRoot, warnings);
  return {
    sessionsDir: resolveDir(gitRoot, 'sessionsDir', config.sessionsDir, DEFAULT_SESSIONS_DIR, warnings),
    branchesDir: resolveDir(gitRoot, 'branchesDir', config.branchesDir, DEFAULT_BRANCHES_DIR, warnings),
    warnings
  };
}

function resolveSession(gitRoot, branch) {
  const { sessionsDir, branchesDir, warnings } = resolveDirs(gitRoot);
  const name = sanitizeBranch(branch);
  const configuredPath = path.join(sessionsDir, `${name}.md`);
  const legacyPath = path.join(gitRoot, LEGACY_SESSIONS_DIR, `${name}.md`);
  const legacy = configuredPath !== legacyPath
    && !fs.existsSync(configuredPath)
    && fs.existsSync(legacyPath);

  return {
    sessionPath: legacy ? legacyPath : configuredPath,
    configuredPath,
    legacyPath,
    legacy,
    sessionsDir,
    branchesDir,
    branchMetadataPath: path.join(branchesDir, name),
    warnings
  };
}

function sessionSearchDirs(gitRoot, sessionsDir) {
  const legacyDir = path.join(gitRoot, LEGACY_SESSIONS_DIR);
  return sessionsDir === legacyDir ? [sessionsDir] : [sessionsDir, legacyDir];
}

/**
 * POSIX single-quote one argument for a command the agent may run. Inside single
 * quotes nothing is special except the closing quote, so `$`, backticks, and
 * double quotes in a configured directory name cannot execute.
 */
function shellQuote(value) {
  return `'${String(value).replace(/'/g, `'\\''`)}'`;
}

module.exports = {
  DEFAULT_SESSIONS_DIR,
  DEFAULT_BRANCHES_DIR,
  LEGACY_SESSIONS_DIR,
  sanitizeBranch,
  shellQuote,
  resolveDirs,
  resolveSession,
  sessionSearchDirs
};
```

  const issueMatch = branch.match(/(\d+)/);
  const issueNumber = issueMatch?.[1];
  const descWords = branch.split(/[-\/]/).filter(w => w.length > 3 && !/^\d+$/.test(w));

  return listSessionFiles(gitRoot, sessionsDir)
    .map(({ file, fullPath }) => {
      let score = 0;
      const lowerFile = file.toLowerCase();

      // Strong match: issue number in filename
      if (issueNumber && lowerFile.includes(issueNumber)) score += 10;

      // Weak match: description words in filename

function detectMismatch(gitRoot, branch, sessionPath, sessionsDir = paths.resolveDirs(gitRoot).sessionsDir) {
  // If exact match exists, no mismatch
  if (fs.existsSync(sessionPath)) return null;

  const expectedName = path.basename(sessionPath);

      if (content.includes(`**Branch**: ${branch}`) || content.includes(`Branch: ${branch}`)) {

### R2 design

**Config file.** `.memento/config.json` (git-root-relative), top-level keys:

```json
{ "sessionsDir": "work/sessions", "branchesDir": "work/sessions/.branches" }
```

- Defaults unchanged: `.memento/sessions`, `.memento/branches`. Validation unchanged (non-empty string, no NUL, relative, inside the root, not the root; else default + warning). A top-level value that is not a JSON object warns and falls back. Warnings name `.memento/config.json`.
- `.claude/config.json` is no longer read for memento. 0.6.0 is unreleased, so there is no compatibility read; a `memento` section there is ignored (pinned by a test).
- Legacy session reading (`.claude/sessions/<sanitized>.md`), root-anchored single-quoted migration command, and HOME exclusion are unchanged.

**Resolver CLI.** `memento/scripts/resolve-session.js`, read-only, reusing `memento/lib/paths.js`:

```
node <memento-root>/scripts/resolve-session.js [--cwd <dir>]
```

- Never creates, moves, or writes anything; never reads or writes `~/.claude/memento-state.json`.
- Resolves git root and current branch from `--cwd` (default `process.cwd()`) with `git rev-parse --show-toplevel` and `git rev-parse --abbrev-ref HEAD`, falling back to `git symbolic-ref --short -q HEAD` for a branch with no commits.
- stdout is always exactly one JSON object; stderr is unused on success.

Success (exit 0):

```json
{
  "ok": true,
  "gitRoot": "/abs/repo",
  "branch": "issue/feature-42/auth",
  "sanitizedBranch": "issue-feature-42-auth",
  "sessionPath": "/abs/repo/.memento/sessions/issue-feature-42-auth.md",
  "sessionExists": false,
  "legacy": false,
  "configuredPath": "/abs/repo/.memento/sessions/issue-feature-42-auth.md",
  "branchMetadataPath": "/abs/repo/.memento/branches/issue-feature-42-auth",
  "sessionsDir": "/abs/repo/.memento/sessions",
  "branchesDir": "/abs/repo/.memento/branches",
  "configFile": "/abs/repo/.memento/config.json",
  "migrationCommand": null,
  "warnings": []
}
```

`migrationCommand` is the same root-anchored, single-quoted `mkdir -p -- … && git -C … mv -- … …` string the hook offers when `legacy` is true, else `null`.

Cannot resolve (exit 1): `{"ok": false, "reason": "not-a-git-repo" | "no-branch", "warnings": []}` (`no-branch` = detached HEAD). Usage error (exit 2): `{"ok": false, "reason": "usage", "message": "…"}`.

**Shared builder.** `paths.migrationCommand(gitRoot, session)` moves out of `session-startup.js` so the hook and CLI emit an identical command.

**Skill invocation of the CLI** (host-neutral; verified on both hosts, see Portability evidence). The mechanism is script-relative lookup: the resolver is `../../scripts/resolve-session.js` relative to the directory containing the skill's `SKILL.md`. On Claude Code that directory is also available as `${CLAUDE_SKILL_DIR}`, which is a convenience for writing the command, not a separate mechanism. Skills say, verbatim:

> Run memento's resolver with Node: `scripts/resolve-session.js` in the memento plugin, i.e. `../../scripts/resolve-session.js` relative to the directory containing this SKILL.md. (On Claude Code that directory is `${CLAUDE_SKILL_DIR}`, so the command is `node "${CLAUDE_SKILL_DIR}/../../scripts/resolve-session.js"`.)

**Memento skills** (`session`, `resume`; `start` examples only): use the injected `📂 Session:` path when its filename equals `<sanitized current branch>.md`; otherwise run the resolver and use its JSON. No validation rules in skill prose. Metadata path likewise (`🗂️ Branch metadata:` or resolver `branchMetadataPath`). `context/sessions.md` keeps "Configuring the location" as the human reference, updated to `.memento/config.json`; its Finding steps point at the resolver. `rules/sessions.md` drops the `valid:` line and points at the resolver.

**Onus skills** (`commit`, `pr`, `status`, `validate-criteria`): (1) use memento's injected `📂 Session:` path if its filename equals `<sanitized current branch>.md`; (2) otherwise, if the memento plugin is available, invoke `memento:session` (Codex `$memento:session`) to resolve it; (3) otherwise skip session-specific steps and say so.
